# Deferred 开发文档

本目录存放已经完成方向性评审、但短期内没有实施计划的开发设计。

## 状态定义

`Deferred` 表示：

- 设计方向仍可能有价值，暂不删除；
- 当前没有明确的近期交付窗口；
- 不应作为当前开发队列或实施承诺；
- 可能仍缺少优先级、owner、产品需求或必要前置条件。

Deferred 文档只有在确认近期需求、实施 owner、优先级、边界和验收条件后，才迁回 `Docs/Planned`。已经实现并与当前代码核对一致的文档迁入 `Docs/Archived`。
